# Requirement — 扫描频率 30min → 2h

- Feature: `scan-frequency`
- Status: `FROZEN`（2026-10-05 项目负责人决策）
- 来源: 负责人明确要求 "降低扫描频率——改成 2 小时一轮"

## 需求条目

| ID | 需求 | 验收 |
|---|---|---|
| REQ-FREQ-01 | 定时扫描由每 30 分钟改为每 2 小时 | cron 表达式 `0 */2 * * *`，整点触发 |
| REQ-FREQ-02 | 前端展示文案同步 | "每 2 小时自动更新" |
| REQ-FREQ-03 | 文档基线同步 | REQUIREMENTS.md 变更记录 + 其他文档一致 |

## 理由（记录于 REQUIREMENTS.md）

单轮全量扫描实测约 16 分钟；30 分钟周期外部 API 调用过密，且第三方按调用计费；AI 新闻传播周期为小时级，2h 不影响时效。
